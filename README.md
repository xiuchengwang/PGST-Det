# PGST-Det

Official project page for **PGST-Det: Polarity-Guided Sparse Trajectory Learning for Event-Based Tiny Flying Object Detection**.

PGST-Det is an event-level framework for detecting tiny flying objects directly from sparse asynchronous event-camera measurements. The method combines polarity-temporal voxel encoding, polarity-guided sparse trajectory processing, polarity-aware spatio-temporal correlation, and target-preserving zoom augmentation.

## Release Status
